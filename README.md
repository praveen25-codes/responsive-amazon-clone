## 📌 About the Project

This project is a frontend clone of the Amazon homepage built using only HTML and CSS.  
It was created to practice real-world web layout design and improve frontend development skills.

The project focuses on recreating the layout and styling of a modern e-commerce website inspired by Amazon.

---

## 🚀 Features

- Fully responsive design for all screen sizes  
- Amazon-like navigation bar  
- Search bar UI layout  
- Hero/banner section  
- Product category sections  
- Footer section with links  
- Clean and structured UI design  

---

## 🛠️ Built With

- HTML5  
- CSS3  
- Flexbox  
- Responsive Web Design
